// 01  WHAT IT DOES

The whole server, in one window

Everything a Rust dedicated server needs doing, done from a control deck instead of a command line.

01

Installs the server

Point it at a folder and it pulls the Rust dedicated server down with SteamCMD for you. No manual SteamCMD scripts, no hunting for the right app id.

02

Start and stop

One control starts the server and one stops it cleanly. The deck shows whether it is running, starting or down, without you reading a log.

03

Backups

Back up the server's save and config on demand, so a bad wipe or a bad plugin is one restore away instead of a lost world.

04

Scheduled wipes

Set the wipe on a schedule and let the deck run it. Map and blueprint wipes on the cadence you choose, not the night you happen to remember.

05

Live players, FPS and console

The player list, the server's FPS and the raw console scroll live in the deck while the server runs. The console is right there to read and type into.

06

One window, no command prompt

Install, run, wipe, back up and watch the server from a single window. You never open a terminal to keep a server alive.

07

Windows and Linux

A signed one-click installer on Windows; a copy-paste install that runs it as a systemd service on Debian, Ubuntu, Fedora and RHEL.

Linux — Debian / Ubuntu or Fedora / RHEL

Linux one-liner

Paste this into a terminal on a server you own. It installs the deck as a systemd service under an unprivileged user, and pulls in the 32-bit libraries and Python it needs automatically.

curl -sSL https://honeybadger.software/installer/install.sh | sudo bash -s -- --from https://honeybadger.software/installer/HoneyBadgerBunker-0.1.0.tar.gz

The deck runs on 127.0.0.1:27800 — loopback only, so it is never exposed to the internet. Reach it from your own machine over an SSH tunnel.

Honest note

HoneyBadger Bunker runs a Rust server on a machine you control — a Windows PC, a VPS, or a dedicated or home Linux box.

It is not for a managed or rented game-server slot from a hosting panel; those do not give you the machine, so the deck has nothing to install onto.

// 04  REQUIREMENTS

What the box needs

A Rust server is a real game server. Give it room and open the two ports it listens on.

01

Memory

Roughly 12 GB of RAM per Rust server. A bigger map or a full population wants the headroom.

02

Disk

Around 15 GB of disk per server for the install, the map and the saves.

03

Ports to forward

Forward UDP 28015 for the game and UDP 28017 for the server query, so players can find and join you.

04

The deck stays private

The control deck's own panel is loopback-only. It is never forwarded; you reach it on the machine itself or over an SSH tunnel.
