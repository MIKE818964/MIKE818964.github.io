RUST DPS METER · ART PACK · v1

The band, file by file

These are the image files every Rust client downloads when the Honey Badger DPS Meter draws its band. They live here as plain static files over https, cached for a year under versioned names, and they are licensed for use with the plugin, including copies you host yourself. Nothing on this page is generated on the fly: what you see is what the client gets.

SELF-HOSTING

Serve the art from your own domain in three steps

By default clients fetch from this site. If you would rather own that traffic, the plugin only needs a folder URL.

  1. Copy the four files above to any https host that serves them as image/png with no login and no redirect. Keep the file names.
  2. In config/HoneyBadgerDps.json set Image base URL (https, ends with /) to that folder, ending with a slash, and reload the plugin.
  3. If you ever replace an image under the same name, change Image cache tag so clients fetch it again. Admins can prove loading with /dps probe; /dps text is the fallback for a client that cannot load images.
