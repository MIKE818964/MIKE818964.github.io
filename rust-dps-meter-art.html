The band, file by file.

These are the image files every Rust client downloads when the Honey Badger DPS Meter draws its band. Plain static files over https, cached for a year under versioned names. Nothing here is generated on the fly: what you see is what the client gets.

// 03  SELF-HOSTING

Your domain, three steps

By default clients fetch from this site. If you would rather own that traffic, the plugin only needs a folder URL.

01

Copy four files

Put band_frame_cleaned_v3.png, badge.png, body_silhouette.png and hitpop_skull_cleaned.png on any https host that serves them as image/png with no login and no redirect. Keep the names.

02

Point the config

In config/HoneyBadgerDps.json set Image base URL (https, ends with /) to that folder, ending with a slash, and reload the plugin.

03

Bump the tag when you swap art

If you ever replace an image under the same name, change Image cache tag so clients fetch it again. /dps probe proves loading as admin; /dps text is the fallback for a client that cannot load images.
