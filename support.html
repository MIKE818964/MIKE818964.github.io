00 / Quick start

Pick a tool, grab it, run it.

Every HoneyBadger product is built to install and run without a terminal. Pick your product, grab it from the Downloads page, and follow the in-app guidance. Each app ships with a built-in Known Issues page so you always know exactly what works and what's still cooking.

Most of this manual covers the HoneyBadger Bunker Rust server deck, since it has the most moving parts. J1 Bridge, the C7 Dashboard and the Dash Builder are further down.

01 / Install · Windows

Install on Windows

Windows 10 or 11, 64-bit. Windows products ship as a single signed installer — no Python, no Docker, no command line. The easiest way is the signed installer.

1

Download the installer

Get HoneyBadgerBunker-Setup-0.1.0.exe from the Bunker page or the Downloads page. It is signed, so there is no "unknown publisher" warning, and it installs per-user with no administrator rights.

2

Run it

Double-click it and follow the prompts. It installs to your account and adds a Start Menu shortcut (and a desktop one if you tick the box).

3

Open the deck

Launch HoneyBadger Bunker from the Start Menu. The deck window opens — no console, no terminal.

Portable zip

Prefer no installer? Download the portable zip, right-click it → Properties → tick Unblock → OK, unzip it anywhere, and double-click HoneyBadger Bunker.bat. The zip carries its own copy of Python, so there is nothing else to install.

Closing the deck window does not stop your server — the engine keeps running in the background. Open the deck again and everything is where you left it.

01 / Install · Linux

Install on Linux

Debian and Ubuntu (64-bit) are the tested path; there is also a newer Fedora / RHEL / Rocky / Alma path. On the server, as root, paste one line:

curl -sSL https://honeybadger.software/installer/install.sh | sudo bash -s -- \
  --from https://honeybadger.software/installer/HoneyBadgerBunker-0.1.0.tar.gz

Already have the source folder on the box? Run sudo bash packaging/linux/install.sh from it instead. The installer is safe to run again, and it will:

  • install the 32-bit libraries SteamCMD needs, plus Python, curl, unzip and logrotate;
  • create an unprivileged user honeybadger — the game server never runs as root;
  • install the deck into /opt/honeybadger and run it as a systemd service named hbdeck;
  • set up log rotation and a restart-on-crash limit so a broken update cannot loop forever.

The deck listens on the server's loopback address only — it is never exposed to the internet. Reach it from your own PC over an SSH tunnel:

ssh -L 27800:127.0.0.1:27800 you@your-server

Then open http://127.0.0.1:27800/ in your browser. Useful commands:

systemctl status hbdeck
journalctl -u hbdeck -f
sudo systemctl restart hbdeck
sudo bash /opt/honeybadger/uninstall.sh            # removes the deck, keeps your servers
sudo bash /opt/honeybadger/uninstall.sh --purge    # removes everything, servers included

02 / First run

First run

The first time the deck opens, the setup wizard walks you through a server: a name, where the files go, the map and how many players. It picks free ports and installs the game for you.

Be patient

The first start is slow on purpose: Rust downloads about 6 GB, then the server generates the map. Expect several minutes before it shows as running. Later starts are much faster. Friends can join the moment the deck shows the server running.

03 / Ports to forward

Ports to forward

PortProtocolPurposeOpen to the internet?
28015UDPGameYes
28017UDPServer query (the server list needs it)Yes
28016TCPRCONNo, unless you manage from outside
Rust+ portTCPRust+ companion app (the deck shows the number)Only if you turned it on
27800TCPThe deck panel on LinuxNever — use the SSH tunnel

These are the defaults; if you change a port in the wizard, forward the numbers the deck shows. Playing on your own network needs no port forwarding — press F1 in Rust and connect by IP:

  • On the same PC as the server: use the loopback address — client.connect 127.0.0.1:28015. 127.0.0.1 only ever means "this machine," so it works only from the server PC itself.
  • From another device on your LAN (another PC, a laptop, a console): use the server PC's local network IP instead — for example client.connect 192.168.1.50:28015. Find the server's IP with ipconfig (Windows) or ip addr (Linux); it is usually a 192.168.x.x address.

05 / Updates

Updates

Updates come from honeybadger.software. The deck checks a signed list, and every file it downloads must match a signature and a checksum or it is refused. You get a plain notice in the deck when there is a new version — nothing installs until you click.

  • Windows: the deck downloads and verifies the new version, then swaps it in when you click and the engine has stopped. Or unzip the new portable zip over the old folder — state\ is not in the zip, so your servers and settings stay.
  • Linux: run the installer again with the new package; your settings and servers are kept.

Updating the Rust server itself is separate: it is one button (or a schedule), and it keeps your mod framework in place afterwards.

06 / Other products

J1 Bridge

Connect your Snapmaker J1/J1s to the same network as your PC, open J1 Bridge, and add the printer by IP under Settings. Drag an STL onto the Home tab to slice → upload → print. See the product page for the full workflow.

Do I need to convert to Klipper?

No. J1 Bridge works on stock V2.8.0 firmware. No flashing, no warranty risk.

My first layer has wiper marks

That's the stock start macro. J1 Bridge patches it automatically — make sure the start-macro patch safety gate is ON in Settings.

06 / Other products

C7 Dashboard

The kit arrives ready to run. Plug into the OBD-II port, mount the touchscreen, and power on from a switched 12V source. The dashboard auto-detects your trim and shows the right gauges. Boost gauges appear automatically on Z06 / ZR1.

Does this reflash or modify my ECU?

No. The dashboard reads the OEM CAN bus passively. No reflash, no tune change, warranty intact. Control features drive their own relays — they never write to the ECU.

Which years and trims are supported?

2014–2019 C7 Stingray, Grand Sport, Z06, and ZR1. Auto trans, M7 manual, and MagneRide are auto-detected.

06 / Other products

Dash Builder

The Dash Builder runs in any modern browser — no install. Pick a style, materials, needle, and units; the preview rebuilds live. The exact SVG you design renders identically on the C7 dashboard.

07 / Troubleshooting

Troubleshooting

Windows says "Windows protected your PC" (SmartScreen)

The signed installer is code-signed by HoneyBadger Software, so you should not see an "unknown publisher" warning. A brand-new signed program can still get a reputation prompt until enough people have downloaded it — click More info, then Run anyway. With the portable zip, right-click → Properties → tick Unblock before you unzip. Signing reputation builds with each download.

The deck window does not open

Open state\logs\launcher.log. If it is empty or unclear, run Bunker (console debug).bat to see what it prints. The window needs the Microsoft Edge WebView2 runtime — Windows 11 has it built in; on Windows 10 it is a free download from Microsoft.

First start takes forever

Normal: the game downloads ~6 GB and then the map generates. Give it several minutes the first time; later starts are quick.

Not enough memory

A Rust server wants about 12 GB of RAM and 15 GB of free disk. If the machine has less, pick a smaller map and fewer players in the wizard.

Players cannot join, but it works for me

The ports above are not reachable from outside. Check the router forward, the Windows or Linux firewall, and — on a cloud host — the provider's security group. Both UDP ports must be open.

Linux service will not start

journalctl -u hbdeck -n 50 shows why. The service gives up after 3 failed starts in 5 minutes on purpose; fix the cause and run sudo systemctl restart hbdeck.

Still stuck?

Tell us what broke on the community page — this is a test release, and that feedback goes straight to the people building it.

08 / FAQ

Frequently asked

Is any of this free?

The Bunker and the HoneyBadger DPS Meter are free. J1 Bridge is free for personal use, and the Dash Builder is free to use in the browser. The C7 Dashboard is a commercial hardware kit. Support the studio if you'd like to feed the badger — nothing essential is paywalled.

Do you collect any data?

No telemetry, no analytics, no "phone home." Your machines are your business.

How do I report a bug or request a feature?

Post in the community or email contact@honeybadger.software. Confirmed limitations go on each product's Known Issues page.
