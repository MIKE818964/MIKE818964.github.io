Honey Badger DPS Meter

A live combat band for Rust servers. DPS, headshots, last hit with body zone and range, your target's HP, accuracy and the weapon in your hands, on one painted card under the compass, measured from the damage that actually landed. One .cs file, zero dependencies, MIT.

The band as the plugin draws it, built here from the same image files every Rust client downloads. Sample numbers.

Real landed damage, not the weapon's stat sheet

Rust calls the damage hook before it applies a hit. The plugin notes the target's health, lets the server apply the hit, and reads the health again one tick later. The difference is what landed after armour, headshot multipliers, other plugins and overkill. A second hit on the same target in the same tick settles the first one on arrival. Hitting a wall, a corpse or yourself never counts.

  • DPS over a rolling window (5 s by default)
  • Headshots, last hit, zone and range in metres
  • Target name with a live HP bar, accuracy by projectiles landed

A settings menu, not a config scavenger hunt

/dps opens a menu with a live preview of the band: METER on or off, STYLE painted art or plain text, HIT POP on or off, RESET SESSION. Every choice is remembered per player across relogs and plugin reloads. Bind it to a key with bind f7 hbdps.menu.

  • On for everyone by default, or opt-in: the server owner decides
  • Optional permission gate honeybadgerdps.use
  • Text style for clients that cannot load images

Zero dependencies. Oxide and Carbon.

No ImageLibrary, no Steam API key, no database. The band art is four PNG files served from this site over https and cached by the client. Server owners who want full independence copy the four files to their own https host and change one config line. The plugin only subscribes to the damage hooks while at least one player has the meter on screen, so an idle server pays nothing per hit.

  • Compiled against the current Rust server assemblies under both Oxide and Carbon
  • Loaded on a Carbon server and on an Oxide test server before release
  • No analytics, no version checks, no remote switches. Ever.
INSTALL

Three steps, no restart.

  1. Download the zip and drop HoneyBadgerDps.cs into oxide/plugins/ (Oxide) or carbon/plugins/ (Carbon). The framework compiles it on the spot.
  2. Watch the server console for Loaded plugin Honey Badger DPS Meter v1.0.0. The config appears as config/HoneyBadgerDps.json, the texts as lang/en/HoneyBadgerDps.json.
  3. Join. The band comes up the first time you wake. Type /dps for the menu. Admins can prove the art loads with /dps probe.

Permissions: honeybadgerdps.use (only checked when the config asks for it; admins always pass) and honeybadgerdps.admin (the probe). Grant with oxide.grant user <steamid64> honeybadgerdps.use; Carbon accepts the same command.

CONFIG

config/HoneyBadgerDps.json, as shipped.

{
  "Meter": {
    "On by default for every player": true,
    "Require the permission honeybadgerdps.use": false,
    "DPS window in seconds": 5.0,
    "Refresh every N seconds": 0.5,
    "Count hits on NPCs (scientists)": true,
    "Count hits on animals": true,
    "Count hits on buildings and deployables": false,
    "Count hits on vehicles, helicopters and Bradley": true
  },
  "Art": {
    "Enabled (false = plain text meter for everyone)": true,
    "Image base URL (https, ends with /)": "https://honeybadger.software/assets/hud/v1/",
    "Image cache tag (change it after replacing the images)": "1",
    "Band distance from the top of the screen (1280x720 units)": 48.0,
    "Band scale": 1.0
  },
  "Hit pop": { "Enabled": true, "Seconds on screen": 0.9 },
  "Chat hint the first time a player wakes up": true
}

Hosting the art yourself: copy band_frame_cleaned_v3.png, badge.png, body_silhouette.png and hitpop_skull_cleaned.png from https://honeybadger.software/assets/hud/v1/ to any https host that serves them as image/png with no login and no redirect, set the base URL to that folder, and bump the cache tag if you ever replace a file under the same name.

QUESTIONS

The ones server owners ask first.

The band shows numbers but no art.
That client could not download the PNGs. /dps probe as admin shows whether the badge loads; /dps text is the fallback for that player. Check the host serves image/png over https with no login.
DPS looks lower than my weapon's damage stat.
The band shows damage that landed after armour and multipliers. That is the honest number, and it is the one that decides fights.
Does it send anything anywhere?
The only traffic is each client's image download from the configured art host. The plugin itself makes no web requests, keeps no analytics and checks for no updates.
Can I move the band?
Up or down and bigger or smaller through the config. It is always horizontally centred under the compass.
Carbon or Oxide?
Both. It was built on a Carbon server and is compiled and loaded under the current Oxide release before every version.
