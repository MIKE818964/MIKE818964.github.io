Honey Badger DPS Meter.

A live combat band for Rust servers: DPS, headshots, last hit with body zone and range, your target's HP, accuracy and the weapon in your hands, on one painted band under the compass, measured from the damage that actually landed. One .cs file, no other plugins required, MIT.

// 01  THE BAND

What a player sees

One band under the compass. Nine things on it, every one measured from hits that landed.

01

DPS

Damage that landed in the last five seconds, divided by five. The window is a config value.

02

Headshots

Landed headshots this session.

03

Body

The silhouette lights the zones you have been hitting on your targets.

04

Total

Every point of damage that landed this session, after armour.

05

Last hit

Damage of the last landed hit, the body zone it struck, and the range in metres.

06

Target

Who you are hitting, with a health bar that follows the victim. Players by name; Rust's NPCs as Scientist, Heavy Scientist, Tunnel Dweller, Dweller or Bandit; animals and structures by name.

07

Acc %

Projectiles that landed over projectiles fired. Shotgun pellets count on both sides.

08

Weapon

The item in your hands, drawn with the game's own icon.

09

Hit pop

Beside the band, on every landed hit: skull, damage, zone, for under a second. Never in the crosshair.

// 02  HOW IT COUNTS

Landed damage, not the stat sheet

The weapon's damage number is a promise. The band shows what the server actually took off the target.

01

The hook fires first

Rust raises OnEntityTakeDamage before the hit is applied. The plugin notes the target's health, lets the server apply the hit, and reads the health again on the next server tick. The difference is what landed after armour, headshot multipliers, other plugins and overkill.

02

Every hit settles once

A second hit on the same target in the same tick settles the first one on arrival; the last hit of the tick settles next tick. Each hit is credited with exactly the health it took.

03

What never counts

Walls, corpses and yourself. Buildings and deployables are off by default; NPCs, animals and vehicles are config switches.

04

What it costs the server

The two damage hooks are subscribed only while at least one player has the meter on screen. Inside the hook: no LINQ, no reflection, no string formatting. Labels are rebuilt on one shared timer (0.5 s by default) and a label is re-sent only when its text changed. Player choices are written to disk at most once every three seconds.

// 04  THE MENU

Settings, not a config hunt

/dps opens a menu with a live preview of the band. Every choice is remembered per player.

01

Meter/dps on · /dps off

On or off. Remembered per player across relogs and plugin reloads.

02

Style/dps art · /dps text

The painted band, or a plain text line for a client that cannot load images.

03

Hit pop/dps pop

The skull beside the band on every landed hit, on or off.

04

Reset session/dps reset

Clears this session's numbers.

05

Live preview

The menu shows the band with your current numbers while you change it. Put the menu on a key with bind f7 hbdps.menu.

06

The owner decides the default

On for everyone, or opt-in with /dps on. An optional permission gate, honeybadgerdps.use, is only checked when the config asks for it; admins always pass.

// 05  INSTALL

Three steps, no restart

01

Drop one file

Download the zip and put HoneyBadgerDps.cs into oxide/plugins/ (Oxide) or carbon/plugins/ (Carbon). The framework compiles it on the spot. No restart.

02

Watch the console

Loaded plugin Honey Badger DPS Meter v1.0.0. The config appears as config/HoneyBadgerDps.json, the texts as lang/en/HoneyBadgerDps.json.

03

Join

The band comes up the first time you wake. Type /dps for the menu. Admins can prove the art loads with /dps probe.

// 07  CONFIG

config/HoneyBadgerDps.json

As shipped in v1.0.0. Every key is a sentence, so the file reads without this page.

{
  "Meter": {
    "On by default for every player": true,
    "Require the permission honeybadgerdps.use": false,
    "DPS window in seconds": 5.0,
    "Refresh every N seconds": 0.5,
    "Count hits on NPCs (scientists)": true,
    "Count hits on animals": true,
    "Count hits on buildings and deployables": false,
    "Count hits on vehicles, helicopters and Bradley": true
  },
  "Art": {
    "Enabled (false = plain text meter for everyone)": true,
    "Image base URL (https, ends with /)": "https://honeybadger.software/assets/hud/v1/",
    "Image cache tag (change it after replacing the images)": "1",
    "Band distance from the top of the screen (1280x720 units)": 48.0,
    "Band scale": 1.0
  },
  "Hit pop": {
    "Enabled": true,
    "Seconds on screen": 0.9
  },
  "Chat hint the first time a player wakes up": true
}
01

DPS window

The number on the band is damage landed in the last N seconds divided by N. Five by default.

02

What counts

NPCs, animals and vehicles on; buildings and deployables off so base raiding does not read as combat. Corpses never count.

03

Band position and scale

Band distance from the top is in the client's 1280 x 720 units; 48 clears the compass and most status strips. The band is always horizontally centred.

04

Chat hint

One line the first time a player wakes up each connection: DPS meter is on. /dps opens its settings.

05

Host the art yourself

Copy the four PNG files to any https host that serves them as image/png with no login and no redirect, set Image base URL to that folder, and bump Image cache tag if you ever replace a file under the same name. Every file, with previews and sizes, is on the art pack page.

// 09  QUESTIONS

The ones owners ask first

01

The band shows numbers but no art

That client could not download the PNGs. /dps probe as admin shows whether the badge loads; /dps text is the fallback for that player. Check the host serves image/png over https with no login.

02

DPS looks lower than my weapon's damage stat

The band shows damage that landed after armour and multipliers. That is the number that decides fights.

03

Does it send anything anywhere?

The only traffic is each client's image download from the configured art host. The plugin itself makes no web requests, keeps no analytics and checks for no updates.

04

Can I move the band?

Up or down and bigger or smaller through the config. It is always horizontally centred under the compass.

05

Carbon or Oxide?

Both. It was built on a Carbon server and is compiled and loaded under the current Oxide release before every version.
